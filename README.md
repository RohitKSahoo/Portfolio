## 🌐 Portfolio Overview & Design Philosophy

This repository contains the source code for my interactive portfolio website. Designed with a cybernetic dashboard aesthetic, it presents my projects, professional history, and developer telemetry through a highly responsive and tactile user interface.

### Key Visual & Interactive Systems
* **Magnetic Navigation Dock**: An OS-inspired dock component featuring fluid scaling, interactive icons, and persistence-backed active states.
* **Kinetic Grid Background**: An interactive background canvas that responds to cursor proximity using vector mechanics and custom ripple equations.
* **Precision Cursor Tracking**: A custom target cursor implementing acceleration, inertia, and state-aware visual feedback.
* **Session Persistence**: Local storage integration ensures state preservation and seamless navigation transitions across page reloads.

---

## 🛠️ Technology Stack

The application is engineered from the ground up, prioritizing high performance and polished micro-interactions:

* **Core Framework**: React 18, TypeScript, Vite
* **Animations & Interaction**: GSAP (GreenSock Animation Platform), Framer Motion
* **Graphics**: Three.js, React Three Fiber (R3F), OGL, React Three Rapier (for physical simulations)
* **Styling**: Tailwind CSS, Custom CSS (utilizing design tokens and responsive typography)
* **Communications**: Contact form integration powered by the Resend API
