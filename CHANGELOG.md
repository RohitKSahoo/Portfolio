# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-04-12
### Added
- **Interactive Project Folders**: Implemented a high-performance `Folder` component with hover-to-reveal kinetics.
- **Dynamic Project Registry**: Redesigned the `RegistryPage` into a grid-to-detail workflow.
- **Side-by-Side Reveal**: Added cinematic paper fan-out animation on hover for project documentation.
- **Magnet Hover Effect**: Implemented mouse-tracking offsets for project cards inside open folders.

### Fixed
- **Folder Persistence**: Resolved issues with folder states overlapping between grid and detail views.
- **Theme Consistency**: Synchronized folder accents with the "Architect Red" portfolio theme.

## [1.1.0] - 2026-04-12
### Added
- **Kinetic Background**: Integrated a Canvas-based `DotGrid` with GSAP `InertiaPlugin` for reactive background physics.
- **Real-time Color Interpolation**: Implemented smooth RGBA transitions for dot-grid focus points.

### Improved
- **Global Layout**: Configured `DotGrid` as a persistent fixed background layer across all dashboard views.

## [1.0.0] - 2026-04-11
### Added
- **System OS Dashboard**: Initial implementation of the high-contrast, technical portfolio dashboard.
- **Robotic Avatar**: Created a mecha-inspired 2D avatar with smooth cursor tracking and blinking logic.
- **Navigation System**: Implemented a vertical OS-style sidebar for page routing.
- **Responsive Registry**: Initial version of the project gallery with vertical `ImageRibbon` navigation.
