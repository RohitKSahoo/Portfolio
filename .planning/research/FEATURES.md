# Research: Features & User Experience

**Analysis Date:** 2026-04-12
**Focus:** Modern Hero Interactivity

## Table Stakes (Required for 2026 Portfolios)

- **Interactive 3D Anchor:** A central visual element that reacts to the pointer (parallax or direct bone manipulation).
- **Kinetic Backgrounds:** Backgrounds that respond to movement with inertia—feeling like a "physical" space rather than a static image.
- **Glassmorphism UI:** Blurred overlays that integrate the UI panels into the visual space.

## Differentiators (Premium Experience)

- **Shockwave Ripple:** A click-triggered displacement in the background grid that propagates outwards.
- **Glitch Physics:** Subtle visual "errors" (chromatic aberration, jitter) triggered by high-speed mouse movement, signaling high system intensity.
- **Micro-Telemetrics:** Floating bits of data (hashes, coordinates) that follow the 3D model, reinforcing the "System OS" theme.

## Anti-Features (Avoid)

- **Autoplay Video Backgrounds:** Replaced by more performant Canvas/WebGL alternatives.
- **Heavy Entry Transitions:** Avoid 2s+ long "loading" animations; use progressive loading with placeholders.
